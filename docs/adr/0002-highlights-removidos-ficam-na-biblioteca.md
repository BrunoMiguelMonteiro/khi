# Highlights apagados no Kobo ficam na Biblioteca

A Biblioteca não é um espelho do Kobo. Um highlight que desaparece do Kobo fica na Biblioteca, marcado como «removido do Kobo», porque o Kobo perde highlights quando um livro é apagado ou reinstalado, ou quando o device é reposto. Guardá-los é a razão de a Biblioteca existir. Só o Kobo de onde o highlight veio o pode marcar como removido: sincronizar outro Kobo do mesmo Leitor nunca o faz.

## Considered Options

- **Espelhar o Kobo (apagar também).** Rejeitado: perde-se precisamente o que a Biblioteca deve guardar.
- **Copiar o `KoboReader.sqlite` em cada Sincronização.** Rejeitado pela mesma razão. Também não junta vários Kobos num Leitor.
